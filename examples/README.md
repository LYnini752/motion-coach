# 高清高尔夫示例 / HD golf samples

打开 Demo 即载入 **1080×1920、16 秒近景慢动作**；点“开始分析”重新运行模型，或点“直接看示例结果”查看实际预计算骨架、图表、关键帧与记录。

## 默认分析片段

- 来源：[Suvichaya Vinijchaitham Golf Swing Slow Mo 2026](https://commons.wikimedia.org/wiki/File:Suvichaya_Vinijchaitham_Golf_Swing_Slow_Mo_2026.webm)，Hut2026，2026-08-14；页面标注作者自摄、[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)。来源称其为 Suvichaya Vinijchaitham 的挥杆练习，不宣称为正式比赛。
- 剪辑：截取原片 0–16 秒，保留竖屏分辨率，30 fps H.264，无音轨；没有加速或放慢。原片本身为慢动作。
- 分析：完整画面，15 fps，置信度 0.65，高尔夫、右侧、侧面。240/240 采样帧有可用关节；这不是准确率或专业动作评分。预计算结果由实际模型生成，不是上传视频的结果。
- 画面投影和慢动作播放时间不能用于推断真实力量或挥杆速度。作者与运动员不为工具背书。

## English

The demo opens with a **1080×1920, 16-second close-up slow-motion swing**. Run local analysis or view the precomputed real skeleton, charts, keyframes and measurements.

Default footage: Hut2026, *Suvichaya Vinijchaitham Golf Swing Slow Mo 2026*, 2026-08-14, own work according to the linked Wikimedia page, CC0 1.0. Extracted 0–16 seconds, silent H.264 at 30 fps, original portrait resolution and playback speed retained. This is practice footage, not a verified tournament recording. Analysis uses the full frame, 15 fps, confidence 0.65, golf/right/side. All 240 sampled frames contained usable joints; this is not an accuracy score. Slow-motion playback and projected coordinates do not measure actual force or swing speed.
